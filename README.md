# Argent Bank – Frontend & Backend

## Backend (API)

### Prérequis
- Node.js >= 16
- npm

### Installation
cd backend
npm install

text

### Lancement
npm start

text

Le serveur écoute sur `http://localhost:3001`.  
La documentation Swagger est disponible sur `http://localhost:3001/api-docs`.

---

## Frontend (React + Vite)

### Prérequis
- Node.js >= 16
- npm

### Installation
npm install

text

### Lancement
npm run dev

text

L’application est accessible sur `http://localhost:5173` (ou le port indiqué dans la console).
